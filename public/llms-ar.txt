# أسد الله شافق — مطور ذكاء اصطناعي وكيل

> ملف تعريف أسد الله شافق: مطور ذكاء اصطناعي وكيل، ومهندس full-stack (Next.js 15 / TypeScript / Python / FastAPI)، ومؤسس شركة Texcot Embroidery Sourcing House، وبطل هاكاثونات Panaversity (ستة انتصارات متتالية، صفر إخفاقات). مقره باكستان، ويخدم أسواق باكستان والإمارات.

هذا الموقع نظام وكيل بحد ذاته: يتضمن وكيل محادثة يعمل بـ OpenAI Agents SDK مع وكلاء متخصصين
وتوجيه بينهم، وخادم MCP حقيقي، وطبقة ذكاء اصطناعي دستوري تفرض مبادئ مكتوبة.

## كيف أبني الوكلاء

- هندسة التجهيز (البيئة): الأدوات والذاكرة والصلاحيات والمراقبة — شبكة الأمان حول النموذج.
- هندسة الحلقة (التغذية الراجعة): الدليل قبل الثقة — الوكيل يتوقف عندما تنجح الاختبارات، لا عندما يشعر بالاكتفاء.
- هندسة الرسم البياني (التدفق): التفرّع والموافقات وإعادة المحاولة والمهام المتوازية — تنسيق سير العمل كاملاً.
